# Azoya Pattu Pavadai - Project Agent Guide

## Project Overview

**Azoya** is a premium e-commerce website for traditional South Indian girls' wear, specifically showcasing **Pattu Pavadai** and **Rajakumari** collections. The project is built on modern web technologies with a focus on cultural heritage and family craftsmanship.

- **Brand**: Sana Creation
- **Purpose**: Showcase and sell traditional Tamil-heritage girls' clothing
- **Target Audience**: Parents seeking authentic, premium traditional wear
- **Heritage**: Premium silk, embroidery, and handcrafted details

## Tech Stack

| Category | Technologies |
|----------|--------------|
| **Frontend Framework** | React 19.0.0 |
| **Build Tool** | Vite 6.0.7 |

## Key Features & Sections

### 1. **Workflow Display**
Shows the dress-making process with 5+ steps:
- Raw Material selection
- Cutting
- Aari/Embroidery work
- Stitching
- Pleating/Iron finishing

Each step uses Lucide icons and descriptive text.

### 2. **Responsive Design**
- Mobile-first approach with Tailwind breakpoints
- Smooth scrolling behavior
- Tap-highlight transparency for better UX

### 3. **Dark Mode Support**
- Configured via `darkMode: 'class'` in Tailwind
- Automatic color transitions (220ms ease)
- Manual toggle capability through JavaScript

### 4. **Gallery System**
- Media assets stored in `public/media/gallery/`
- Integrated with React components

### 5. **Custom Typography**
- Font: Inter (system fallbacks: ui-sans-serif, system-ui)
- Separate display and body font families defined

## Component Architecture

- Contains all workflow steps configuration
- Exports React App as default
- Uses Lucide icons for each workflow stage

## Styling Guidelines

### Tailwind Usage
- Use utility classes for responsive design: `md:`, `lg:`, etc.
- Custom shadows: `shadow-glass` (subtle), `shadow-glow` (rose-tinted)
- Always use Azoya color tokens: `text-azoya-rose`, `bg-azoya-mist`

### Global Styles (`styles.css`)
- Base reset with Tailwind directives
- Smooth scrolling enabled
- Optimized font rendering
- No tap highlight for better mobile experience

## Common Development Tasks

### Adding a New Product Section
1. Create section component in `main.jsx`
2. Add Lucide icon for visual consistency
3. Use Azoya color palette
4. Ensure responsive with Tailwind breakpoints

### Adding Gallery Images
1. Place images in `public/media/gallery/`
2. Reference with `/media/gallery/filename.ext`
3. Optimize images for web (JPG/WebP, <100KB)

### Implementing Dark Mode Toggle
1. Detect if dark mode is enabled
2. Add/remove `dark` class to `<html>` element
3. Use Tailwind dark mode utilities: `dark:bg-azoya-ink`

### Updating Brand Colors
1. Modify values in `tailwind.config.js` under `colors.azoya`
2. Tailwind will regenerate utility classes
3. No restart needed with Vite dev server

## Performance Considerations

- **Asset Optimization**: Images in gallery should be <100KB
- **Code Splitting**: Vite auto-splits chunks; no manual config needed
- **Build Size**: React 19 + minimal deps = ~60KB gzipped
- **Dark Mode**: CSS transitions enable smooth theme switching

- Semantic HTML in index.html
- Icon buttons pair with text labels
- Color contrast follows WCAG standards (via Tailwind)
- Smooth transitions reduce motion sickness risk

## File Editing Rules for This Project

When modifying code:
- **Imports**: Keep lucide-react imports organized alphabetically
- **Color Classes**: Always use `azoya-*` tokens, never hardcoded hex
- **Responsiveness**: Test on mobile (320px), tablet (768px), desktop (1024px+)
- **Icons**: Match icon choice to section purpose (e.g., `Gem` for luxury)
